MATLAB 的两处接缝速度最小值约 2.595 m/s；原生版本约 3.000 m/s。它们在连接处没有为了重新规划而停车。倒车换向处的零速是停车轨迹自身的运动要求。

MATLAB 的两份基础实现 `.m` 已移出发布目录，仅保留 `.p` 后重新运行 `RunMe.m`，验证了 `status=stitched`、验证标志通过、窗口数量恰为 2。README 图片来自该次实际运行。

C++ 与 Python 使用同一受保护后端，选中组合和代价一致；MATLAB 的原始 Reeds–Shepp/AMPL 基础规划与原生初始化、求解器不同，所得局部解不同。这里没有宣称三种语言逐点重现同一数值轨迹，也没有宣称复现论文全部实验统计。

机器负载影响计时。Python 工作池在计时前初始化，C++ 计时包含工作进程启动；这些单次值不是公平的语言性能基准。默认只完整验证了算例 1，不把打包的其他算例冒充为全部通过。

## 截止时间回退

对 C++/Python 额外运行 `--deadline`，二者均在避障规划阶段触发 1.2 秒预算，终止求解工作进程，返回 `fail_safe_evasion_or_deadline`。制动输出离散足迹无碰撞。C++ 返回耗时约 1.223 s，Python 求解/回退报告计时约 1.204 s（不含随后工作池销毁时间）。

因此本机完整缝合计算**没有达到论文的 1.2 秒在线预算**。回退分支已实测；默认演示模式允许求完所有候选。MATLAB 的截止开关只拒绝迟到结果，不能中途打断同步 LIOM 调用。
